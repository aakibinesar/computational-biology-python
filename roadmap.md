# Roadmap

This file outlines future improvements planned for the repository.

The first polished portfolio version of this repository is complete. Future work will focus on expanding depth, improving usability, and turning selected parts into stronger research and teaching outputs.

## Current Milestone

**First polished portfolio version: complete**

Completed components include:

- original Rosalind solution archive;
- curriculum map;
- problem dependency map;
- solved problem index;
- module README files;
- tutorial notebooks;
- ML-ready sequence feature mini-project;
- teaching materials;
- workshop record;
- project status documentation.

## Near-Term Improvements

### 1. Improve Notebook Depth

Future versions may expand the tutorial notebooks with:

- more biological examples;
- additional explanations;
- more exercises;
- solution-checking cells;
- clearer links to the original Rosalind problems.

### 2. Expand the ML-ready Sequence Features Mini-project

The current mini-project creates a first version of a sequence feature extraction workflow.

Future improvements may include:

- larger example FASTA datasets;
- additional k-mer feature options;
- GC-skew features;
- codon-usage features;
- simple classification examples;
- clustering visualizations;
- train/test workflow examples;
- cleaner command-line interface.

### 3. Add More Teaching Exercises

The teaching section currently contains first-version exercise sheets.

Future improvements may include:

- answer keys;
- instructor notes;
- timing plans;
- beginner and advanced versions;
- short quizzes;
- more Biopython-focused exercises;
- project-style assignments.

### 4. Add GitHub Pages Documentation

A future version may convert the repository into a small public learning website using GitHub Pages.

Possible pages:

- learning path;
- module index;
- notebook index;
- mini-projects;
- teaching materials;
- Rosalind problem map.

### 5. Add Utility Code

Some reusable helper functions from the notebooks may later be moved into small Python modules.

Possible utilities:

- FASTA parsing helpers;
- nucleotide counting;
- reverse complement;
- GC content;
- k-mer counting;
- sequence feature extraction;
- alignment helper functions.

### 6. Strengthen Research Connections

Future versions may connect the repository more directly to research interests such as:

- biological sequence representation;
- machine learning for biological sequences;
- DNA-domain computation;
- computational biology education;
- reproducible bioinformatics workflows.

## Longer-Term Ideas

Possible long-term additions:

- a small biological sequence classification project;
- a comparison of classical k-mer features and learned sequence representations;
- a Rosalind-to-ML bridge notebook;
- a teaching workshop package;
- a GitHub Pages version of the curriculum;
- a publication-style technical report describing the curriculum design.

## Not Currently Planned

The following are intentionally not part of the current version:

- full machine learning model development;
- deep learning sequence models;
- large-scale biological datasets;
- full production-level software packaging;
- replacing the original Rosalind archive;
- uploading private workshop materials or participant data.

## Guiding Principle

The repository will continue to follow this direction:

Rosalind problem solving
→ computational biology curriculum
→ tutorial notebooks
→ reusable teaching materials
→ ML-ready biological sequence workflows
