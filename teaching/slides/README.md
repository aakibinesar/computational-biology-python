# Slides

This folder is reserved for notes about lecture slide topics from the original workshop.

The original workshop included slide decks on workshop introduction, the concept of programming languages, variables and expressions, string operations, flow control, lists, repetition, dictionaries and tuples, input/output, FASTA and FASTQ, and Biopython sessions.

## Public Repository Approach

The current repository does not need to include every original slide deck.

Instead, this folder can preserve a public-facing index of topics and explain how the slide content was converted into notebooks and exercises.
